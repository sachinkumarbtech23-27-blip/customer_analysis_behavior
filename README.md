# customer_analysis_behavior
End-to-end retail analytics and customer segmentation on 3.9K transactions ($233K revenue). Features EDA, statistical dashboards, and an interactive executive presentation uncovering behavioral trends, demographic gaps, and promotional anomalies
📊 End-to-End Data Analytics Pipeline & Dashboard
📌 Overview
This project demonstrates a comprehensive, end-to-end data analytics lifecycle. It covers data ingestion and exploratory data analysis (EDA) in Python, cross-platform relational database querying across PostgreSQL, MySQL, and Microsoft SQL Server, interactive business intelligence reporting in Power BI, and executive-ready presentation delivery using Gamma.

The primary objective is to transform raw, unstructured data into actionable business insights that drive strategic decisions.
